---
name: do-issue
description: GitHub issue の内容を実装・検証し、PR と CI 確認まで進める。issue の実行を依頼されたときに使う。
---

issue とリポジトリの指示を読む。repo 固有の `do` スキルがある場合はその手順を使う。ユーザーが範囲やブランチを指定済みなら従い、なければ repo 規約の base から作業する。

issue の受け入れ条件に必要な実装と検証を行い、変更をコミット・push して PR を作る。PR に issue と実施した検証を記載し、CI の結果を確認する。計画や委譲の規模はタスクに合わせる。issue のアサイン・ラベル変更・追加コメントは依頼または repo の運用に必要な場合に行う。
