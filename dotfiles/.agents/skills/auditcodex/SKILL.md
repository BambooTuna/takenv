# Codex による独立レビュー

対象はユーザー指定を優先し、指定がなければ未コミット差分、なければ直近コミットとする。未追跡ファイルも対象か確認する。目的・対象・既知の制約・指示ファイルの場所を brief に含める。

`codex exec --help` で利用中の CLI を確認する。レビューは `codex exec --sandbox read-only -C <repo> -o <result-file> -` へ brief を stdin で渡して実行する。モデルはユーザー指定または設定の既定値を使う。一時ファイルは `mktemp -d` 配下に置き、並行監査と衝突させない。

レビュー担当には、コードを変更せず、不具合が起きる条件・影響・該当行・根拠を報告させる。指摘ゼロも有効な結果。好みだけの変更は求めない。

終了状態と結果ファイルを確認し、指摘を実装・要件と照合して採否を判断する。監査だけの依頼なら指摘を返す。修正まで依頼されていれば、採用した指摘を修正・検証まで進める。
