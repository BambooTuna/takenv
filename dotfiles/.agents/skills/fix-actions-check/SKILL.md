---
name: fix-actions-check
description: 現在の PR の CI 失敗を調査・修正し、結果を確認する。CI 修正を依頼されたときに使う。
---

現在の PR と失敗したチェック・ログを取得する。リポジトリの CI 定義とローカル再現手順を読み、原因に対応する修正と検証を行う。セキュリティスキャンの失敗も内容を確認し、名前だけで無視しない。

修正したコミットを push し、`gh pr checks` で再実行の結果を確認する。待機は短い観測間隔で行い、失敗・権限不足・実行待ちを区別する。関連しない作業を抱き込まず、外部障害や権限不足は根拠と未完了部分を報告する。
