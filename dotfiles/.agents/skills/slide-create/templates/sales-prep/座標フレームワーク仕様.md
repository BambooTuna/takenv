# スライド構成の基本仕様

> プレゼンテーションスライドを構成する全要素と配置ルールの定義

---

## 1. キャンバス

スライドは**真っ白な矩形のキャンバス**。全ての要素はこの上に配置される。

| 属性 | 値（16:9の場合） |
|---|---|
| 幅 | 13.33 inches（960px @72dpi） |
| 高さ | 7.5 inches（540px @72dpi） |
| 背景色 | 白（#FFFFFF）がデフォルト。変更可能 |

---

## 2. 要素（Element）

キャンバスの上に配置するもの。全ての要素は以下の共通属性を持つ。

### 2-1. 共通属性（全要素に適用）

| 属性 | 説明 | 単位 |
|---|---|---|
| **位置（x, y）** | 要素の左上隅の座標。キャンバス左上が原点（0, 0） | px or inches or EMU |
| **サイズ（w, h）** | 要素の幅と高さ | 同上 |
| **右下座標** | （x + w, y + h）で決まる。左上座標+サイズから算出 | 同上 |
| **z座標（重なり順）** | 前面/背面の順序。数字が大きいほど前面に来る | 整数 |
| **背景色** | 要素の塗りつぶし色。透明も可 | HEXカラー |
| **枠線** | 下記参照 | — |

**枠線の属性:**

| 属性 | 説明 | 例 |
|---|---|---|
| 有無 | 枠線を表示するか | true / false |
| 色 | 枠線の色 | #1e3a5f, #e0e0e0 |
| 太さ | 枠線の太さ | 0.5pt, 1pt, 2pt |
| 種類 | 線のスタイル | 実線、破線、点線、二重線 |
| **回転** | 要素の回転角度 | 度 |

### 2-2. 要素の種類

キャンバスに配置できる要素は以下の種類がある。

#### ① 矩形（Rectangle）

| 属性 | 説明 |
|---|---|
| 背景色 | 塗りつぶし色 |
| 枠線 | 色、太さ、スタイル |
| 角丸 | 角の丸みの半径 |

用途: 背景ブロック、カード、ハイライトボックス、区切り

#### ② テキストボックス（TextBox）

| 属性 | 説明 |
|---|---|
| 背景色 | 透明 or 塗りつぶし |
| 枠線 | 色、太さ、スタイル |
| 内部余白 | 上下左右のパディング |
| テキスト | 中に入るテキスト（後述） |
| 自動サイズ | テキストに合わせて拡縮するか、固定か |

用途: 見出し、本文、注釈、ラベル

#### ③ 表（Table）

| 属性 | 説明 |
|---|---|
| 行数・列数 | テーブルの構造 |
| 列幅 | 各列の幅 |
| 行高さ | 各行の高さ |
| セル | 各セルにテキスト+背景色+枠線 |
| ヘッダー行 | 背景色を変えてヘッダーを区別 |

用途: データの比較、一覧

#### ④ 線（Line）

| 属性 | 説明 |
|---|---|
| 始点（x1, y1） | 線の開始座標 |
| 終点（x2, y2） | 線の終了座標 |
| 色 | 線の色 |
| 太さ | 線の太さ |
| スタイル | 実線、破線、点線 |
| 矢印 | 始点/終点に矢印をつけるか |

用途: 接続、フロー、区切り線

#### ⑤ 図形（Shape）

| 属性 | 説明 |
|---|---|
| 形状 | 円、楕円、三角形、矢印、吹き出し等 |
| 背景色 | 塗りつぶし色 |
| 枠線 | 色、太さ |

用途: アイコン代わり、強調マーク、フロー図の構成要素

#### ⑥ 画像（Image）

| 属性 | 説明 |
|---|---|
| ファイルパス | 画像ファイルの参照 |
| トリミング | 表示範囲の切り取り |

用途: ロゴ、スクリーンショット、写真

#### ⑦ グループ（Group）

| 属性 | 説明 |
|---|---|
| 子要素 | 複数の要素をまとめて1つとして扱う |
| 移動・拡縮 | グループ全体を一括操作 |

用途: 複合的な図表、レイアウトの固定

## 3. テキスト（Text）

テキストボックスや表のセルの中に入るテキスト。テキストは以下の階層構造を持つ。

```
テキストボックス
  └─ 段落（Paragraph）  ← 改行で区切られる単位
       └─ ラン（Run）    ← 同じ書式が適用される文字列の単位
```

### 3-1. 段落（Paragraph）の属性

| 属性 | 説明 | 例 |
|---|---|---|
| 配置 | 左揃え、中央揃え、右揃え | 見出し=左、タイトル=中央 |
| 行間 | 行と行の間隔（相対値 or 絶対値） | 1.0, 1.3, 1.5 |
| 段落前の間隔 | 段落の上側の余白 | Pt(6) |
| 段落後の間隔 | 段落の下側の余白 | Pt(6) |
| インデント | 左端からの字下げ | レベル0, 1, 2... |
| 箇条書き | 先頭記号の有無と種類 | ・、1.、① |

### 3-2. ラン（Run）の属性

1つの段落内でも、部分ごとに異なる書式を適用できる。それが「ラン」。

| 属性 | 説明 | 例 |
|---|---|---|
| **フォント名** | 書体 | Noto Sans JP |
| **フォントサイズ** | 文字の大きさ | 14pt, 18pt, 24pt |
| **色** | 文字の色 | #1e3a5f, #dc2626 |
| **太字** | 太字にするか | true / false |
| **斜体** | 斜体にするか | true / false |
| **下線** | 下線をつけるか | true / false |
| **取り消し線** | 取り消し線 | true / false |

### 3-3. フォントの特殊事項

PowerPoint/PPTXでは、1つのランに対して複数のフォントタグを持つ:

| タグ | 用途 | 例 |
|---|---|---|
| **latin** | 半角英数字に適用 | Calibri, Arial |
| **ea（East Asian）** | 全角文字（日本語等）に適用 | Noto Sans JP, Meiryo |
| **cs（Complex Script）** | アラビア語等に適用 | — |

日本語スライドでは**latinとeaの両方を設定**しないと、英字と日本語で異なるフォントが適用されるか、フォールバックされて意図しない見た目になる。

## 4. 配置の原則

### 4-1. 座標系

```
(0, 0) ──────────────────── x軸 ──→ (幅, 0)
  │
  │   キャンバス
  │
  y軸
  │
  ↓
(0, 高さ) ──────────────────────── (幅, 高さ)
```

- 原点は**左上**
- x: 右に行くほど大きい
- y: 下に行くほど大きい
- 全ての要素は（x, y, w, h）で配置される

### 4-2. 重なり（z座標）

- 要素は追加順に重なる（後から追加したものが前面）
- 明示的にz座標を変更して前面/背面を制御可能
- 典型例: 背景の矩形（最背面）→ テキストボックス（前面）

### 4-3. 単位

| 単位 | 説明 | 変換 |
|---|---|---|
| EMU | PowerPointの内部単位 | 1 inch = 914,400 EMU |
| inches | インチ | 1 inch = 72pt |
| pt（ポイント） | フォントサイズ等 | 1 pt = 12,700 EMU |
| px（ピクセル） | 画面表示の参考値 | 解像度依存（72dpi想定） |

python-pptxでは `Inches()`, `Pt()`, `Emu()` で変換する。

## 5. 「伝わるスライド」にするための配置

上記の要素と属性は「道具」に過ぎない。目的は**伝えたい情報が最も視覚的に伝わること**。

### 5-1. 視覚的に伝えるとは

人間の目は以下の順序で情報を処理する:

1. **大きさ・色のコントラスト** → 最初に目に入る（0.1秒）
2. **位置関係** → 何と何が関係しているか（0.5秒）
3. **テキストの読み取り** → 具体的な内容を理解（数秒）

### 5-2. 要素の属性と視覚効果の対応

| 伝えたいこと | 使う属性 |
|---|---|
| **これが重要** | 大きいフォント、太字、赤など目立つ色 |
| **これとこれは同じグループ** | 近い位置に配置、同じ背景色の矩形で囲む |
| **これとこれは違う** | 離れた位置、異なる色 |
| **AからBへ変化した** | 左→右に配置、矢印で接続 |
| **量の大小** | 要素の面積（棒の長さ、円の大きさ） |
| **時間の流れ** | 左→右、または上→下に順序配置 |
| **補足・注意書き** | 小さいフォント、グレー色、下方に配置 |

### 5-3. よくあるレイアウトパターン

| パターン | 構造 | 使用場面 |
|---|---|---|
| **中央1メッセージ** | 大きな文字を画面中央に | タイトル、メッセージスライド |
| **上:見出し + 下:表** | 上1/4に見出し、下3/4に表 | データ提示 |
| **左右対比** | 左と右に同サイズの要素 | Before/After、2社比較 |
| **上→下のフロー** | 上から下に矢印で接続 | プロセス説明 |
| **グラフ+表** | 上にグラフ、下に表 | 視覚→詳細の2段階提示 |

---

*以上。スライドは「白いキャンバスに要素を重ねて配置する」もの。要素の種類・座標・サイズ・色・テキスト属性が全て。これらを「伝えたい情報が最も伝わるように」組み合わせる。*
