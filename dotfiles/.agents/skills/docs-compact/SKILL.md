# 文章の整理

読み手が知りたい結論を先に置き、理由・根拠・次の行動へつなげる。各段落は一つの要点に絞り、比較や手順は必要なときだけ表・箇条書きにする。

- 挨拶の重複、同じ結論の言い直し、内容のない強調、過剰な見出しを削る。
- 固有名詞、数値、条件、留保、否定、出典、URL は意味を変えない。引用・コード・構造化データは、編集対象として指定された場合だけ直す。
- 専門語は読み手に合わせる。用語の言い換えで精度が落ちるなら、元の語を残して短く説明する。
- 短くするために根拠や重要な例を落とさない。原文から判断できない事実は補わない。

出力形式はユーザー指定を優先し、通常は編集済み本文を返す。意味を変える判断が必要だった箇所だけ補足する。
