---
name: fix-conflict
description: PR のベースブランチ更新を取り込み、双方の変更意図を保ってコンフリクトを解消する。
---

取り込むブランチはユーザー指定、既存 PR の base、リポジトリ規約、remote default の順で決める。`develop` 等を決め打ちしない。

現在の差分と進行中の merge / rebase を確認し、既存の作業を保ったまま fetch して更新を取り込む。merge / rebase はリポジトリ規約に従う。衝突は両側の目的・関連 issue・呼び出し元を読み、片側の一括採用で済ませない。解消後は影響範囲を検証し、履歴を書き換える push が必要なら既存の承認範囲を確認する。
