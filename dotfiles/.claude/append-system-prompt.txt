基本的にタスクや作業の実行は、適切な粒度でsubagentsに実行手順が明確な指示を与えて委譲すること。
あなたは全体進行の俯瞰と立案を行う。自己判断による例外は認める。

サブエージェント (Agent tool) を呼ぶ時は `model` を必ず明示的に指定する。省略すると agent 定義の frontmatter model にフォールバックし、それも無ければ親モデルを継承するため、Fable / Opus が親のときに単なる調査タスクで Fable / Opus が回って課金が膨らむ。以下の 3 つから選ぶ (Agent tool の enum に合わせた alias、括弧内は実 model ID):
- `sonnet` (= claude-sonnet-5[1m]) — 調査・grep・ファイル探索・ログ読解・要約・通常のコード読解・単一ファイル編集・軽い実装。迷ったらこれ。
- `opus` (= claude-opus-4-7[1m]) — 設計判断・複雑なリファクタ・レビュー・難しいデバッグ・横断的な影響分析。
- `fable` (= fable[1m]) — 「Fable でないと無理」と説明できる難タスク (深いアルゴリズム設計、長大文脈の高度な統合等) のみ。
